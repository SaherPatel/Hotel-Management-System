Hotel Management System – Version 1.0
Introduction

The Hotel Management System is a software system designed to manage basic hotel operations. It helps hotel staff manage rooms, customers, bookings, check-in, and check-out activities.

Version 1.0

Version 1.0 provides the basic functionality required for managing hotel room bookings and customer stays.

Features
1. Room Booking

The hotel staff can book an available room for a customer.

2. Booking Cancellation

The hotel staff can cancel an existing room booking.

3. Customer Management

The system stores basic customer information such as customer name, contact details, and booking information.

4. Room Availability

The system maintains the availability status of rooms.

5. Check-In

Hotel staff can check in customers who have a valid room booking.

6. Check-Out

Hotel staff can check out customers after completion of their stay.

Version 1.0 Objective

The main objective of Version 1.0 is to provide basic room booking, cancellation, customer management, room availability, check-in, and check-out facilities.
